# diary-temp-dev

muz님의 크래커 다이어리 **v2.3.23**을 고친 개선판(Temp2)입니다. 필요한 부분은 자유롭게 가져다 쓰세요.

- 파일: [`Cracker-Diary_v2.3.23_Temp2_UTF-8-BOM.txt`](Cracker-Diary_v2.3.23_Temp2_UTF-8-BOM.txt)
- 사용법: 파일 내용을 Tampermonkey 새 스크립트에 붙여 넣습니다. 스크립트 이름이 달라 원본과 따로 설치되므로, 원본은 꺼 주세요.

## 원본과 달라진 점

### 1. 사용 기록을 저장해서 오래된 기록이 사라지지 않음

| | 원본 | Temp2 |
|---|---|---|
| 조회 범위 | 매번 최대 50쪽까지 | 처음에 끝까지 한 번 받고, 이후에는 마지막 조회일까지만 |
| 일별 합계 | 저장 안 함, 매번 새로 계산 | `db.usage`에 저장 |
| 50쪽을 넘는 옛 기록 | 합계에서 빠짐 | 그대로 남음 |
| 1분마다 하는 자동 새로고침 | 매번 처음부터 다시 조회 | 보통 몇 쪽이면 끝남 |
| 조회 실패 시 | 이전 수치를 유지하지만, 새로 열면 다시 받아야 함 | 저장된 기록을 바로 표시하고, 저장값도 그대로 유지 |

- 첫 전체 수집은 빨리 끝나도록 4쪽씩 동시에 받습니다. 요청 제한(HTTP 429)에 걸리면 2초 쉬고 한 쪽씩 받습니다.
- 동시 수집 중 새 기록이 생겨 쪽이 밀리면 해당 구간을 다시 받아 누락을 막습니다.
- 수집이 중간에 실패하면 저장하지 않으므로, 불완전한 값이 기록을 덮어쓰지 않습니다.
- 기존 저장 키를 그대로 씁니다. 메모·스티커 등 기존 데이터는 유지되고, 새 필드는 `usage`와 `usageThrough`뿐입니다.
- 복원한 백업에 `usage`가 없으면 전체 수집을 다시 합니다.

### 2. 통계 탭에 카드 2개 추가

- **🏆 전체 통계**: 총 누적 사용, 사용한 날, 사용일 평균, 최다 사용 달
- **🗓️ 월별 사용량**: 달별 합계와 막대, 사용일 수, 사용일 평균
  - 월간 한도를 넘은 달은 막대를 빨간색으로 바꾸고 "한도 초과"를 표시합니다.
  - 달을 누르면 그 달이 선택되어 아래 기존 통계에 반영됩니다.

합계는 달력과 같은 기준(보정값 포함, 0 이하는 미사용)으로 계산합니다.

### 3. 오늘의 크래커 카드에 월간 한도 막대 추가

일일 한도 막대 아래에 `이번 달 사용량 / 월간 한도` 막대를 넣었습니다. 설정에 있던 기존 월간 목표값을 그대로 씁니다.

## 코드에서 바뀐 곳

- 추가: `mergeUsage`, `usageOverview`, `overview()`, `collectPages`, `DIARY_FETCH_WIDTH`, `.month-row` CSS
- 수정: `refresh()`(수집과 저장), `summary()`(월간 막대), 탭 렌더링, 클릭 처리, 백업 복원

`@version`은 원본과 같은 2.3.23이고, `@name`만 다릅니다.

## 확인한 범위

기록 합치기, 전체·월별 합계, 쪽 단위 수집(동시 수집 중 새 기록 발생, 429 포함)은 가짜 서버를 이용한 자동 테스트로 확인했습니다. 실제 사이트 응답으로 검증한 결과는 아니므로, 적용 전에 직접 확인해 주세요.
